預備拍每一拍都是重音、不響細分，畫面會顯示「預備」。循環時就是【預備】【樂句】【預備】【樂句】… 一直重複；靜音訓練從樂句第一小節開始數，漸快只算樂句的小節。

速度由每支手機自己依同一組參數推算，所以加速的瞬間不會斷拍。 到達目標之後就維持不變。

靜音訓練 關閉
每 小節，靜音 小節

靜音的那幾小節拍子照走，只是不出聲。畫面上的格子會用比較暗的 方式繼續跑，讓你知道現在在第幾拍。這是練內在節奏最有效的方法之一—— 撐過去之後聲音回來，就知道自己有沒有跑掉。

我的耳機延遲 0 ms

如果你聽到的拍子比別人慢，往右拉，直到跟大家一致。 有線耳機通常不用調，藍牙耳機大約在 120–250 之間。這個設定只影響你自己。

聽不到的時候，先換隔音好的耳機，再考慮用音量鍵調大。 長時間大音量會傷聽力，而且是不可逆的。

曲目 0 首

點一首會把速度、拍數、重音、細分、漸快、預備拍設定一次套用到整個房間。

存的速度：「耗時」有填原曲速度就用它，沒填就用目前速度；兩個不一樣會問你。 長度從「耗時」帶過來。之後點這首，會把速度和長度填回「耗時」。

歌單 0 個

點歌單就會開始：節拍器上方會出現「下一首」，按一下全房換成下一首的速度、拍號和重音。按 ✎ 可以加歌、排順序。
